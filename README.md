# Awesome AI CLI [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of CLI tools that supercharge AI coding agents.

AI coding agents like [Claude Code](https://anthropic.com/claude-code) and [Codex CLI](https://github.com/openai/codex) are changing how we build software. But their real power comes from the tools you give them access to. Every CLI on this list is a capability your agent can use — managing infrastructure, sending emails, deploying code, processing payments, or searching Discord history — all from the terminal, no browser or GUI needed.

**This list focuses on CLIs that are particularly useful when paired with AI coding agents.** If an agent can run it, and it replaces clicking through a web UI, it belongs here.

## AI Coding Agents

The agents themselves — the tools that consume all the other CLIs on this list.

- [Claude Code](https://anthropic.com/claude-code) - Anthropic's agentic CLI for terminal-based coding. Runs commands, edits files, and manages your entire dev workflow.
- [Codex CLI](https://github.com/openai/codex) - OpenAI's lightweight terminal coding agent. Open-source, built in Rust.
- [Cline CLI](https://cline.bot) - Open-source coding agent with Plan/Act modes, terminal execution, and MCP integration. 59k+ GitHub stars.
- [Cline Kanban](https://cline.bot/kanban) - Orchestrate multiple CLI coding agents (Claude Code, Codex, Cline) in parallel with task management and real-time diff viewing.

## Cloud & Infrastructure

Provision, deploy, and manage cloud resources without leaving the terminal.

- [AWS CLI](https://aws.amazon.com/cli/) - Official CLI for Amazon Web Services. Manage every AWS service from the terminal.
- [Google Cloud CLI (gcloud)](https://cloud.google.com/sdk/gcloud) - Official CLI for Google Cloud Platform. Create VMs, manage Kubernetes, configure networking, and more.
- [Cloudflare Wrangler](https://github.com/cloudflare/workers-sdk) - CLI for Cloudflare Workers — create, test, and deploy serverless functions and manage Cloudflare configuration.
- [Laravel Forge CLI](https://github.com/laravel/forge-cli) - Manage Forge servers and sites — initiate deployments, manage environment variables, SSH, and view logs.
- [Stripe Projects](https://projects.dev) - Stripe CLI plugin that lets agents provision backend services, generate credentials, and manage subscriptions.

## Developer Services

Ship faster with CLIs for email, version control, voice, and more.

- [GitHub CLI (gh)](https://cli.github.com/) - The official GitHub CLI. Create PRs, manage issues, trigger workflows, review code — all from the terminal.
- [Resend CLI](https://github.com/resend/resend-cli) - Official CLI for Resend — send emails, manage domains, API keys, contacts, broadcasts, and webhooks.
- [ElevenLabs CLI](https://github.com/elevenlabs/cli) - Manage voice agents and speech synthesis from the command line.

## Communication & Messaging

Let your agent send messages, search chat history, and manage communications.

- [Kapso CLI](https://kapso.ai) - WhatsApp Business API from the terminal — send/receive messages, manage templates, and resolve numbers.
- [discrawl](https://github.com/steipete/discrawl) - Archive, search, and browse Discord server history locally via SQLite. By [@steipete](https://github.com/steipete).

## Financial & Payments

Manage money, cards, and transactions programmatically.

- [Ramp CLI](https://github.com/ramp-public/ramp-cli) - Financial operations from the terminal — manage cards, bills, expenses, and approvals. JSON output mode for scripting and agents.
- [Visa CLI](https://visacli.sh) - Make programmatic card payments from the terminal without managing API keys. Beta from Visa Crypto Labs.

## Productivity & Office

Access email, documents, calendars, and notes without opening a browser.

- [Microsoft 365 CLI](https://github.com/pnp/cli-microsoft365) - Manage Microsoft 365 tenants from any platform — SharePoint, Teams, Outlook, OneDrive, OneNote, and more.
- [Google Workspace CLI (gws)](https://github.com/googleworkspace/cli) - Official CLI for Google Workspace — Drive, Gmail, Calendar, Sheets, Docs, Chat, and Admin. 22k+ stars.
