# Contributing

Thank you for your interest in contributing to Awesome AI CLI!

## Guidelines

### What belongs here?

A CLI tool belongs on this list if:

- **It's a real CLI** — installed and run from the terminal, not a GUI or web app.
- **It's useful for AI coding agents** — it replaces a browser-based workflow with terminal commands that an agent like Claude Code or Codex CLI can execute.
- **It's maintained** — the project is actively developed and functional.

### How to add a tool

1. Fork the repository.
2. Add the tool to the appropriate category in `README.md`.
3. Use the format: `- [Name](URL) - Short description ending with a period.`
4. Submit a pull request with a brief explanation of why the tool is useful for AI agents.

### Quality standards

- One tool per pull request.
- Check that the tool isn't already listed.
- Descriptions should be concise (one line) and explain what the tool does, not what it is.
- Links should point to the official source (GitHub repo preferred, official website otherwise).
